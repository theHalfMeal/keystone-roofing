# Keystone Roofing & Exteriors — sample website

A single-page reference site for a roofing contractor, built as a sales sample. Keystone is a fictional company.

- Glass top bar that becomes a floating pill, with a services mega menu, phone number, light/dark toggle (dark by default) and a full-screen phone menu
- Before/after drag slider with momentum
- Instant roof estimate: home size, stories, pitch and material give a live price range, roof squares, install days and a monthly payment
- Pinned "install day" scroll story with a running clock
- Services grid, example reviews, ZIP code coverage check, FAQ
- Sticky Call / Get Estimate bar on phones

Plain HTML, CSS and JavaScript — no build step.
